# UT99 Nexgen — Project Instructions

Follows the shared rules in `UT99\CLAUDE.md` (parent folder). Nexgen is the UT99
server administration/management mod suite.

## Key Files

| File | Purpose |
|---|---|
| `Nexgen.ini` | Nexgen controller configuration |
| `Nexgen112N.u` | Nexgen 112N compiled UnrealScript package |
| `NexgenABM201N.u` | Nexgen Advanced Ban Manager compiled package |
| `NexgenCC.u` | NexgenCC compiled package |
| `NexgenPlayerLookup.ini` | NexgenPlayerLookup configuration |
| `NexgenPlayerLookup112N.u` | NexgenPlayerLookup compiled package |
| `MEMORY.md` | Persistent project memory (read at session start) |
