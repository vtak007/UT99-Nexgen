# UT99 Nexgen

Reference archive of **known-good compiled packages** for Nexgen, the UT99 server
administration/management mod suite, and a couple of its plugins. This repo holds compiled
`.u` binaries as a baseline, not buildable source — there is no `Source`/`Classes` folder here.

## What's in here

| File | Purpose |
|---|---|
| `Nexgen112N.u` | Nexgen 112N — the core server admin/management package |
| `NexgenABM201N.u` | Nexgen Advanced Ban Manager |
| `NexgenCC.u` | NexgenCC |
| `NexgenPlayerLookup112N.u` | NexgenPlayerLookup |

## Why keep this

These are pinned, known-working versions used as a reference baseline across other UT99 server
projects (e.g. as `ServerPackages` dependencies) — a known-good copy to diff against or restore
from if a server install drifts, rather than a mod actively developed here.
